The Purpose Behind Visual Documentation

When building cloud-native infrastructure for autonomous coding agents, visual proof is essential for reproducibility, security auditing, and onboarding. These images document five distinct stages in the agent sandbox lifecycle:

1. Conceptual Distinction

Developers often confuse standard Fly Apps (Fly Machines) with Fly Sprites. The comparison image visually cements that while Apps target incoming HTTP web traffic, Sprites target sandboxed agent execution with 100 GB persistent storage and instant resume checkpoints.

2. Headless Dev Ergonomics

The web terminal captures reveal real hurdles developers face (such as browser popup blocks during OAuth, keyring encryption warnings in ephemeral shells, and port binding to 0.0.0.0:8080) with practical step-by-step resolution.

3. Autonomous Agent Execution

The final chrometerminal workflow shows the concrete hand-off: an agent receives a structured prompt, automatically targets organization erdem-391, configures Key Vault secrets, and deploys the mascot web app without manual friction.

1. The Architectural Baseline Matrix

Why this asset is in the repository: To eradicate the biggest developer misconception before writing a single line of code. Fly Apps are built for web traffic; Fly Sprites are built for autonomous code execution.

  • Zero Docker overhead: Agents boot straight into a preconfigured Ubuntu/Debian microVM.
  • 100 GB built-in persistent disk: Backed by object storage with NVMe tiered caching.
  • Checkpoint & Restore: Hibernate immediately when idle, restoring memory state in sub-seconds.

Fly.io Sprites Quick Reference Cheatsheet

Synthesized from the commands and prompts proven in the assets folder.

1. Authenticate

Logs into Sprites service & issues organization token.

sprite login
2. Create Sprite Instance

Spins up persistent 100 GB microVM in organization.

sprite create -o erdem-391 mimo-sprite
3. Expose Public URL

Allows unauthenticated public browser access to port 8080.

sprite config update --url-auth public
4. Fast Health Check Server

Quick static verification inside the new Sprite microVM.

python3 -m http.server 8080
